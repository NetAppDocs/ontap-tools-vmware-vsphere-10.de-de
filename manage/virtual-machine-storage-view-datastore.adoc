= Details zum Speicher virtueller Maschinen in ONTAP tools anzeigen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
In der Speicheransicht werden die vVols angezeigt, die einer virtuellen Maschine zugeordnet sind.


NOTE: Diese Ansicht gilt für VMs mit mindestens einer Festplatte aus einem von ONTAP tools for VMware vSphere verwalteten vVols Datenspeicher.

.Schritte
. Gehen Sie vom vSphere-Client zur virtuellen Maschine.
. Wählen Sie im rechten Fensterbereich die Registerkarte *Monitor* aus.
. *NetApp ONTAP tools* > *Storage* auswählen. Die *Storage*-Details erscheinen im rechten Bereich. Die Liste der vVols auf der VM ist sichtbar.
+
Die Option *Spalten verwalten* ermöglicht das Ein- oder Ausblenden von Spalten.
