= Ändern Sie das Kennwort des ONTAP Tools Managers
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können das Administratorkennwort im ONTAP tools Manager ändern.

.Schritte
. Starten Sie den ONTAP Tools Manager über einen Webbrowser: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. Melden Sie sich mit Ihren ONTAP tools for VMware vSphere Administratoranmeldeinformationen an.
. Das *Administrator*-Symbol in der oberen rechten Ecke auswählen und *Passwort ändern* auswählen.
. Im Dialogfeld „Passwort ändern“ das alte und das neue Passwort eingeben. Die dort angezeigten Passwortrichtlinien prüfen.
. Wählen Sie *Ändern*, um die Änderungen anzuwenden.
