= Starten Sie SSH auf anderen ONTAP tools-Knoten
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Bevor ONTAP tools for VMware vSphere aktualisiert werden, sollte SSH auf jedem der anderen Knoten in Ihrer Umgebung gestartet werden.

.Bevor Sie beginnen
Aktivieren Sie die VASA Provider-Erweiterung für Ihre vCenter Server-Instanz.

.Über diese Aufgabe
Wiederholen Sie diesen Vorgang auf jedem Knoten vor dem Upgrade.

.Schritte
. Melden Sie sich beim vCenter Server an.
. Die ONTAP tools Knoten-VM suchen und die Webkonsole öffnen.
. Melden Sie sich mit den  `maint` Zugangsdaten an.
. Geben Sie ein `4`, um *Support und Diagnose* auszuwählen.
. Geben Sie  `1` ein, um *Access diagnostic shell* auszuwählen.
. Eingabe `y` Fortfahren.
. Führen Sie den Befehl  `sudo systemctl restart ssh` aus.
