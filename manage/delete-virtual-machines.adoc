= Bereinigen Sie die VASA-Konfigurationen in ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die folgenden Schritte führen zur vollständigen VASA-Bereinigung in ONTAP tools.


NOTE: Alle vVols Datenspeicher sollten entfernt werden, bevor die VASA-Bereinigung gestartet wird.

.Schritte
. Öffnen  `\https://OTV_IP:8143/Register.html`, um das Plug-in zu deregistrieren.
. Vergewissern Sie sich, dass das Plug-in nicht mehr auf dem vCenter Server verfügbar ist.
. Die ONTAP tools for VMware vSphere virtuelle Maschine (VM) wird heruntergefahren.
. Löschen Sie ONTAP Tools für VMware vSphere VM.
