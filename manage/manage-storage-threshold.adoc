= Speicherschwellenwerte in ONTAP tools verwalten
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können Speicherschwellenwerte festlegen, um Benachrichtigungen im vCenter Server zu erhalten, wenn das Volumen oder die Aggregatkapazität ein bestimmtes Niveau erreicht.

.Schritte
. Melden Sie sich beim vSphere-Client an.
. Wählen Sie auf der Shortcuts-Seite unter dem Plug-ins-Abschnitt *NetApp ONTAP Tools* aus.
. Gehen Sie im linken Bereich der ONTAP -Tools zu *Einstellungen* > *Schwellenwerteinstellungen* > *Bearbeiten*.
. Im Fenster *Schwellenwert bearbeiten* die gewünschten Werte in den Feldern *Fast voll* und *Voll* eingeben und *Speichern* auswählen.
+

NOTE: Die Schwellenwerte können auf die empfohlenen Standardwerte zurückgesetzt werden: 80 für Fast voll und 90 für Voll.
