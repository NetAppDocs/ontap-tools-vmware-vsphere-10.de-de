= Aktualisieren Sie die vCenter Server-Anmeldeinformationen in ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Verwenden Sie die Wartungskonsole, um die Anmeldeinformationen der vCenter Serverinstanz zu aktualisieren.

.Bevor Sie beginnen
Sie benötigen die Zugangsdaten für den Wartungsbenutzer.

.Über diese Aufgabe
Wenn Sie die Anmeldeinformationen für den vCenter Server nach der Bereitstellung geändert haben, aktualisieren Sie diese mit diesem Verfahren.

.Schritte
. Melden Sie sich beim vCenter Server an.
. Die ONTAP tools VM suchen und die Webkonsole öffnen.
. Melden Sie sich mit den  `maint` Zugangsdaten an.
. Geben Sie ein `2` , um das Menü Systemkonfiguration auszuwählen.
. Eingeben `8` um die vCenter-Anmeldeinformationen zu ändern.
