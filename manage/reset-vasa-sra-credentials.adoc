= VASA-Provider- und SRA-Anmeldeinformationen in ONTAP tools zurücksetzen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Falls Sie Ihre VASA Provider- oder SRA-Zugangsdaten vergessen, kann im ONTAP tools Manager ein neues Passwort festgelegt werden. Das neue Passwort muss zwischen 8 und 256 Zeichen lang sein.

.Schritte
. Starten Sie den ONTAP Tools Manager über einen Webbrowser: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. Melden Sie sich mit den ONTAP Tools für VMware vSphere Administrator-Anmeldeinformationen an, die Sie während der Implementierung angegeben haben.
. Wählen Sie die Option *Einstellungen* > *VASA-Anbieter-/SRA-Anmeldeinformationen* > *Passwort zurücksetzen*.
. Geben Sie das neue Passwort ein und bestätigen Sie es.
. Wählen Sie *Speichern*, um die Änderungen zu übernehmen.
