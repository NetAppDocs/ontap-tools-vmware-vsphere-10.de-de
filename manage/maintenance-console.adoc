= ONTAP tools Wartungskonsole
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Wartungskonsole für ONTAP tools for VMware vSphere ermöglicht die Verwaltung von Anwendungs-, System- und Netzwerkeinstellungen.  Sie können Administrator- und Wartungspasswörter aktualisieren, Support-Bundles generieren, Protokollierungsstufen konfigurieren, TLS-Einstellungen verwalten und die Ferndiagnose aktivieren.

Nach der Bereitstellung von ONTAP tools for VMware vSphere ist bei nicht erreichbarer Wartungskonsole die Installation der VMware Tools vom vCenter Server erforderlich. Die Anmeldung erfolgt mit dem `maint` Benutzernamen und dem während der Bereitstellung festgelegten Passwort. *nano* dient zum Bearbeiten von Dateien in der Wartungs- oder Root-Anmeldekonsole.


NOTE: Ein Passwort für den  `diag`Benutzer wird festgelegt, wenn die Remote-Diagnose aktiviert wird.

Über die Registerkarte *Zusammenfassung* Ihrer bereitgestellten ONTAP tools für VMware vSphere kann auf die Wartungskonsole zugegriffen werden. Zum Starten der Wartungskonsole image:../media/launch-maintenance-console.gif["Wiedergabetaste"] auswählen.
