= Das Anwendungsbenutzerpasswort in ONTAP tools zurücksetzen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Das Anwendungsbenutzerkennwort, das VASA Provider und SRA zur Registrierung beim vCenter Server in ONTAP tools for VMware vSphere verwenden, wird zurückgesetzt.

.Schritte
. Öffnen Sie einen Webbrowser und gehen Sie zu `https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. Melden Sie sich mit den Administratoranmeldeinformationen an, die während der Bereitstellung der ONTAP -Tools konfiguriert wurden.
. Wählen Sie in der Seitenleiste *Einstellungen* aus.
. Auf der Seite *VASA/SRA-Zugangsdaten* wählen Sie *Passwort zurücksetzen*.
. Geben Sie das neue Passwort ein und bestätigen Sie es.
. Wählen Sie *Zurücksetzen*, um das neue Passwort anzuwenden.
